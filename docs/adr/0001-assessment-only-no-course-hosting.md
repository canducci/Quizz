# Assessment and certification only, no course hosting

Quizz tests Learners and issues Certificates; it does not host course content (lessons, videos, modules). Creators keep their courses on whatever platform they already use and send Learners to Quizz to be assessed. Hosting courses would put us in competition with established course platforms, while an independent "assess and certify" service fills a gap and lets an Assessment cover a topic rather than depend on a particular course.
