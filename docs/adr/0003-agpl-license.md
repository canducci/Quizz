# Licensed under AGPL-3.0

Quizz is open source under AGPL-3.0, not a permissive license such as MIT or Apache-2.0. We intend to run the official hosted Quizz, and AGPL requires anyone who offers a modified version as a network service to publish their changes, which stops a competitor from taking the code closed-source. The trade-off is that some companies won't adopt or contribute to AGPL code. Changing the license later needs the agreement of every contributor (or a CLA), so this is hard to reverse.
